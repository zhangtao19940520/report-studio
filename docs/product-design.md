# 产品设计文档 — 日报工作台（Daily Report Studio）

> 状态：设计定稿 v1.0 · 原型：`./prototype.html`

## 1. 背景与目标

现有 `daily_report.sh` 通过命令行生成工作日报，存在以下痛点：

- 无界面，浏览历史日报只能翻 Markdown 文件
- 项目配置硬编码在脚本中，新增项目需改代码
- 生成过程黑盒，看不到执行进度与失败原因

目标：做一个本地桌面应用，覆盖「浏览 → 管理 → 生成」日报的完整闭环，替代手工执行脚本。

## 2. 用户与场景

单人使用（开发者本人），典型场景：

| 场景 | 频率 | 动作 |
|---|---|---|
| 下班前生成当日日报 | 每日 1 次 | 选项目 → 点「立即生成」→ 看终端日志确认 |
| 回顾/写周报 | 每周 1~2 次 | 按日期浏览各项目日报与提交明细 |
| 新项目接入 | 不定期 | 新增项目：名称 + 前后端仓库路径 + git 作者 |

## 3. 功能设计

### 3.1 项目管理（侧边栏）

- 项目列表：名称、日报篇数、今日是否已生成（绿点标识）
- 新增项目：弹窗填写 项目名称 / 后端仓库路径 / 前端仓库路径 / git 作者
- 编辑/删除项目（v1.1）
- 全局统计卡片：本周提交数、本周新增行数、日报覆盖情况

### 3.2 日报浏览

- 左侧日期时间轴：按日期倒序，无提交的日期置灰
- 右侧日报详情，三个区块：
  1. **今日工作总结** — 2~6 条要点，按主题归纳
  2. **代码提交明细** — 前后端分组，每条含短 hash、时间、message、feat/fix/chore 标签着色
  3. **变更统计** — 前后端各自的 +行 / -行 / 文件数卡片
- 空状态：无日报时提示「点击立即生成日报」

### 3.3 手动生成日报

- 项目头部「▶ 立即生成日报」按钮
- 生成过程以**弹窗**展示：实时流式执行日志（git 采集 → claude 生成 → 入库）+ 状态徽标（生成中/完成/跳过/失败）
- 生成完成后弹窗提供「确认关闭」与「↻ 重新生成」两个操作；生成中两个按钮禁用
- 幂等：当日日报已存在则跳过；**历史日报支持强制重新生成**（弹窗重新生成按钮 / 日报详情页「↻ 重新生成」），执行时先删除旧日报再重建
- **补生成**：项目头部「📅 补生成」按钮，选择过去任意日期生成该日日报（应对忘记生成的场景；该日已有日报则跳过，可配合强制重新生成覆盖）

### 3.4 报告存储原则

- **SQLite 为日报数据唯一来源**（总结、提交明细、统计、正文均落库）
- 现有 `{key}_work_report.md` 仅在首次启动时一次性导入
- **导出功能**（3.5）：页面支持将日报导出为 Markdown / Excel / PDF 三种格式

### 3.5 设置

- 入口：项目头部「⚙ 设置」按钮
- 字体大小：小 / 中 / 大（实时预览，localStorage 持久化）
- 主题色：赤橙 / 青蓝 / 松绿 / 紫藤 / 鎏金 五色预设，实时预览（基于 CSS 变量 + color-mix 派生透明色）
- 字体：使用系统本地中文字体（PingFang SC / Songti SC / SF Mono），无需网络加载

### 3.6 汇总报告（周报/月报）

- 主区域顶部 Tab 切换「日报 | 汇总」，日报视图不变；汇总视图为左侧汇总列表（倒序）+ 右侧详情
- 「＋ 生成汇总」弹窗：快捷选择 **近 7 天 / 本月 / 上月 / 自定义区间**（自定义复用日历范围选择）
- 生成逻辑：把区间内各天的日报内容（总结 + 提交明细 + 统计）发给 claude 归纳为汇总要点，连同分日概览一并落库
- 区间内缺日报时，生成前明确列出缺失日期，用户可选「继续（跳过缺失天）」或「取消先去补生成」；区间内完全没有日报则不可生成
- 汇总详情：AI 总结要点（编号列表）+ 覆盖天数 + 分日统计概览（提交数/增删行）
- 汇总支持删除（二次确认）与重新生成（先删后建）
- 同一区间重复生成走强制重建，不产生重复记录

### 3.7 AI 生成器双通道（CLI / API）

- 背景：日报/汇总的 AI 总结目前依赖本机 Claude CLI，换机器部署不可用
- 方案：LLM Provider 抽象，两种模式可切换，生成逻辑（prompt/JSON 解析）完全复用：
  - **Claude CLI（默认）**：现有 `claude -p --output-format json` 实现，零配置
  - **自定义 API**：OpenAI 兼容协议 `POST {url}/chat/completions`，配置 base URL / API Key / 模型 ID
- 配置入口：设置弹窗「AI 模型」分组；API Key 存本地 SQLite（个人本机工具，明文可接受），不进日志
- 「测试连接」按钮：发送最小请求验证配置，生成前即可发现配错
- CLI 模式下未检测到 claude 命令时，生成报错并提示切换 API 模式

### 3.8 导出

- 单日导出：日报详情页导出当日内容
- 范围导出：选择项目 + 日期区间，汇总导出（为写周报服务）
- 格式：Markdown（保持现有格式）、Excel（每行一条提交/或按日汇总）、PDF（渲染排版后打印）

## 4. 非功能需求

- 纯本地运行，数据不出机器（claude CLI 调用除外）
- 首次启动自动导入现有 md 日报，零配置可用
- 生成失败可重试，日志可追溯（generation_run 表）

## 6. 验收标准

- 现有 siem/dlp 两份 md 导入后，界面展示与文件内容一致
- 对当天有提交的项目执行生成，md 文件追加正确格式小节，DB 索引更新
- 重复生成同一天，幂等跳过，不产生重复小节
- 新增项目后可立即浏览（空状态）并执行生成
